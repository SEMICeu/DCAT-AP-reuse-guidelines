# DCAT-AP reuse guidelines
This is the issue tracker for the maintenance of the DCAT-AP reuse guidelines.

SEMIC uses [DCAT-AP](https://semiceu.github.io/DCAT-AP/releases/3.0.1/) as a master profile of DCAT, which means that all DCAT-AP profiles must comply with the [requirements and restrictions imposed by DCAT-AP](https://semiceu.github.io/DCAT-AP/releases/3.0.1/#provider-requirements), namely mandatory properties and [controlled vocabularies that must be used](https://semiceu.github.io/DCAT-AP/releases/3.0.1/#controlled-vocs) with select properties. The process of creating a new DCAT-AP profile therefore starts from a minimal DCAT-AP profile, gradually extending it to cover the requirements driving the creation of a new profile.In the first part of this guide, we cover the process of creating a new DCAT-AP profile in 4 steps. In the second part, we cover the most common problematic situations in more detail and suggest approaches to deal with them.


The latest version of the DCAT-AP reuse guidelnes (v1.0.0) can be downloaded via [SEMIC Support Centre](https://interoperable-europe.ec.europa.eu/collection/semic-support-centre/solution/dcat-ap-reuse-guidelines/release/10).
The HTML of this specification can be found [here](https://semiceu.github.io/DCAT-AP-reuse-guidelines/).

The latest version of DCAT-AP (3.0.1) is published [here](https://semiceu.github.io/DCAT-AP/releases/3.0.1/).

The latest version of DCAT-AP Annex for High Value Datasets (3.0.0) is published [here](https://semiceu.github.io/DCAT-AP-reuse-guidelines/). A public review of the next version is open until September 2026. The draft version (v3.0.1) can be viewed [here](https://semiceu.github.io/DCAT-AP/drafts/3.0.1-hvd/).

Other Relevant links:
- [Respec](https://respec.org/docs/)

Any problems encountered, or suggestions for new functionalities can be submitted as issues on the DCAT-AP reuse guidelines repository on GitHub. A short guideline for submitting issues can be found at https://github.com/SEMICeu/DCAT-AP/wiki/Submission-guidelines.
